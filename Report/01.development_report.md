# Refrigerator_09 개발 보고서

## 1. 개요

`Refrigerator_09`는 냉장고 사진에서 재료를 인식하고, 인식된 재료를 바탕으로 레시피를 추천하며, 사용자 프로필과 저장 레시피를 관리하는 웹 애플리케이션입니다.

이번 작업에서는 OpenRouter API 기반의 3단계 기능을 구현하고, C++ 기반 에이전트 역할 정의, 백업 브랜치 생성, 성능/UX 개선, GitHub `dev` 브랜치 업로드까지 진행했습니다.

## 2. 브랜치 및 업로드 현황

- 원격 저장소: `https://github.com/pjb5592/Refrigerator_09.git`
- 작업 브랜치: `dev`
- 백업 브랜치: `backup/dev-before-agent-improvements`
- 최신 업로드 커밋:
  - `592127f` 냉장고 레시피 웹 애플리케이션 구현
  - `3ad8ba0` 에이전트 등록 정보 추가 및 앱 안정성 개선

`.env`와 `data/app-data.json`은 `.gitignore`에 의해 업로드 대상에서 제외했습니다.

## 3. 구현된 주요 기능

### 1단계: 이미지 인식

- 냉장고 이미지 업로드 UI 구현
- JPG, PNG, WebP 파일 검증
- 이미지 미리보기 제공
- OpenRouter 이미지 모델 호출 API 구현
- 모델 응답을 재료 목록과 불확실 항목으로 정규화
- 이미지 인식 실패 시에도 수동 재료 입력 가능

기본 모델:

```text
google/gemma-3-27b-it:free
```

실제 테스트용 override:

```text
google/gemma-3-27b-it
```

### 2단계: 레시피 추천

- `/api/generate-recipes` API 구현
- 재료 목록과 사용자 선호도를 기반으로 레시피 생성
- 레시피 카드 UI 구현
- 사용 재료, 추가 필요 재료, 조리 시간, 난이도, 조리 단계 표시
- OpenRouter 응답 JSON 안정화를 위해 `response_format`과 프롬프트를 보강

기본 모델:

```text
deepseek/deepseek-chat-v3.1:free
```

실제 테스트용 override:

```text
deepseek/deepseek-chat-v3.1
```

### 3단계: 프로필 및 저장 레시피

- 로컬 개발용 프로필 저장 API 구현
- 저장 레시피 생성, 조회, 검색, 삭제 API 구현
- 저장 레시피 UI 구현
- 사용자 선호도를 레시피 생성 기본값으로 재사용
- 로컬 데이터 저장 위치: `data/app-data.json`

## 4. C++ 에이전트 구현

`agents/agent_roles.cpp`에 다음 역할의 에이전트 정의를 추가했습니다.

- `performance-optimizer`: 성능 최적화 전문가
- `ux-design-advisor`: UX 디자이너
- `code-bug-analyzer`: 코드 버그 분석가
- `product-manager`: 프로덕트 매니저
- `server-side-engineer`: 서버 사이드 개발 전문가
- `client-side-engineer`: 클라이언트 사이드 개발 전문가
- `quality-manager`: 품질 관리 전문가
- `llm-integration-expert`: LLM 통합 전문가

실행 명령:

```bash
npm run agents:build
npm run agents:run
```

검증 결과 C++ 빌드와 실행이 성공했습니다.

## 5. 성능 및 UX 개선
